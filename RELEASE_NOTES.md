# AimCoach Desktop 0.1.0-alpha.1-candidate

**UNPUBLISHED ALPHA DRAFT. Public download is not available yet.**

Windows x64 portable candidate, built with Godot 4.7.2. The executable includes
its runtime resources. The accepted ZIP contains AimCoach.exe, README-FIRST.txt
and THIRD-PARTY-NOTICES.txt.

## Existing features

- Benchmark v6, Precision v7, Switching v8, Tracking v9, Practice v10 and Tracking Practice v11.
- Explicit local JSON/CSV saving, Saved practices discovery and read-only reopening.
- Recorded camera Replay and Esc to stop practice and release the mouse.

## Verification and known limits

Engineering checks covered standalone EXE startup, saving six recording formats,
Saved reopening, Replay, 1280x800 and 1024x640 client areas, and normal exit on
one Windows 11 Pro x64 computer. Physical mouse movement was confirmed for v11;
other format checks used stationary synthetic input and do not establish physical
input behavior in every mode or human training performance.

The executable is unsigned. Its file icon is custom; the runtime titlebar retains
the Godot icon. Final human visual acceptance remains a public-release condition.
Other hardware/OS compatibility, sustained FPS, historical performance comparability
and improvement in other games are not established.

Website import acceptance is separate. Series relationship manifests are not
ordinary single-session JSON imports. Public release and website launch remain
pending. Third-party notices inside the ZIP do not grant an open-source license
to AimCoach application code.
