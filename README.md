# AimCoach Desktop — Windows Alpha

**WINDOWS ALPHA DOWNLOAD PENDING. No Release has been published.**

This is the public repository for AimCoach Desktop binary distribution information.
The application development source is not provided here. No Desktop download is
currently available from this repository. A future approved release will provide
a versioned application ZIP; GitHub source archives of this documentation are not
the Desktop application.

AimCoach Desktop lets you practise aiming locally, review your result, and replay
recorded camera movement. The Windows x64 candidate is a portable ZIP: extract
it, then run AimCoach.exe. Godot, Python, an account and an internet connection
are not required for local practice.

Choose Save practice after a run to save JSON and CSV on your computer. Saved
practices reopens recordings for read-only Replay. The application does not
automatically upload recordings. Website JSON import compatibility remains a
separate acceptance check.

## Alpha limitations

The executable is unsigned. Engineering acceptance covered one Windows 11 Pro
x64 computer; other Windows versions, hardware and sustained performance are
unverified. The EXE file icon is custom, while the application titlebar retains
the Godot icon. Features and compatibility may change. No improvement in other
games is guaranteed.
